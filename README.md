# weather-prediction
🌤️ Weatherly – Weather Prediction App

Weatherly is a simple and user-friendly weather prediction application designed to provide accurate and easy-to-understand weather information. The app helps users check their current weather, hourly forecast, and upcoming 7-day forecast so they can plan their day accordingly.

✨ Features
🌍 Location Access – Uses the user's current location to provide local weather updates.
🌡️ Current Weather – Displays the current temperature and weather condition.
🕐 Hourly Forecast – Shows weather conditions for upcoming hours.
📅 7-Day Forecast – Provides weather predictions for the next seven days.
💧 Humidity Information – Displays the current humidity percentage.
☀️ Weather Conditions – Uses simple weather icons to represent sunny, cloudy, and other conditions.
🎨 Simple UI – Clean, modern, and easy-to-use interface.

Users can view the weather prediction for the upcoming seven days, including temperature and weather conditions.

🎯 Purpose

The main purpose of Weatherly is to make weather information simple, accessible, and easy to understand. It helps users quickly check the weather and plan their daily activities.
